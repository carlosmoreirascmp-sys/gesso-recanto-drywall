# Landing pages Drywall — Gesso Recanto

Duas ofertas independentes, publicadas pelo mesmo projeto na Vercel:

- Obra, fornecimento e instalação opcional: https://obra-drywall.gessorecantosp.com.br/
- Materiais completos para drywall: https://materiaiscompletosdrywall.gessorecantosp.com.br/

O `vercel.json` identifica o domínio de materiais e encaminha suas páginas e arquivos
para a pasta `materiais/`. A página principal permanece dedicada ao serviço de obra.
